# 台北 Taipei｜城市旅遊指南

台北的繁體中文單頁旅遊介紹網站，以純 HTML + CSS + 少量原生 JavaScript 製作，無建置流程。

## 內容

- 主視覺與城市導言
- 必訪景點 8 處：台北 101、國立故宮博物院、中正紀念堂、艋舺龍山寺、象山步道、北投溫泉、迪化街、大安森林公園
- 美食推薦 8 項：夜市小吃、牛肉麵、小籠包、珍珠奶茶、滷肉飯、刈包、蚵仔煎、芒果冰
- 交通資訊：捷運、公車、機場捷運、悠遊卡
- 實用資訊：最佳旅遊季節、天氣、電壓與插座、語言、貨幣與支付、時區

## 瀏覽

線上位址：https://lh11m5.github.io/Taipei/

本機預覽：直接以瀏覽器開啟 `index.html` 即可。

## 檔案

| 檔案 | 說明 |
| --- | --- |
| `index.html` | 頁面內容與導覽邏輯 |
| `styles.css` | 版面、配色與響應式樣式 |

頁面無外部圖片依賴，主視覺的台北 101 為手寫 SVG，其餘裝飾以 CSS 漸層與色塊構成。
